# 文档需求与实现差距

本页自 2026-11-06 核对 AuroraHarness 当前工作树与[文档站路线图](https://haha-ha-cuo.github.io/AuroraAgent-demo/roadmap)、设计目标、架构、协议和前端接入说明，2026-11-07 继续补齐重试与调用轨迹证据。项目仍未完成全部需求。生成安装包、现有测试通过、界面能显示某个状态，都不能替代功能验收。

## 判定规则

- **已覆盖**：所列范围有实现及对应测试或运行证据，不延伸为整个领域已完成。
- **部分实现**：已有可用路径，但缺少需求中的关键行为。
- **未实现**：缺少入口或执行路径，或者仅有占位。
- **待验证**：证据不足，不能算完成。
- **契约偏离**：行为、接口或数据结构与文档不一致，需要兼容收敛；不能通过删除需求把差距改成已完成。

文档站同时包含早期 demo 和目标产品设计。旧目录及历史 Electron 验证不要求在单仓重建；功能要求仍按验收行为核对。当前单仓分层、pnpm 11、uv 及本地 ADR 约束继续适用。对相互冲突的描述单独记录，不能把旧 demo 的勾选直接算作当前仓库完成。
