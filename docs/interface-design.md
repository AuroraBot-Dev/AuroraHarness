# 界面与自定义体验

## 产品方向

工作台承接目标，Agent 承接长期职责，提示词库承接可复用的表达，设置承接模型、协作流程与外观偏好。用户可以从这些入口调整工作方式，不需要从默认角色与默认 Prompt 开始使用。

主导航只放已有功能：工作台、Agent、提示词库；设置位于侧栏底部。工作区使用单一切换器，下方只展示当前工作区的最近对话；实际任务仍由现有运行时执行。

工作区切换菜单显示名称与路径，并收纳添加、重命名和删除入口。默认展示最近 8 个对话，可展开全部；正在查看的旧对话保持可见。收起侧栏时只显示当前工作区的首字标识，点击后可切换工作区和访问对话。手机底栏也提供工作区入口。会话的重命名与删除保留在行尾菜单，避免所有工作区树同时展开。

首页只显示任务标题、工作区和输入框，移除宣传口号、快捷卡片与重复的最近会话列表。设置按外观、模型与协作、工具连接、运行时分类，一次呈现一组配置。Agent 的历史与配置细节默认收起，复制和启停位于更多操作中。

## 视觉规则

界面采用连续画布：内容铺满窗口，不再在系统窗口内嵌套灰色留边、圆角框和投影。首页以左对齐的大字、轻微错位的输入区和一处折光圆弧形成辨识度；不增加快捷卡片或额外信息。

默认樱桃红，用户可用预设、取色器或 `#RRGGBB` 调整。背景光影跟随用户选择的原色，文字与按钮使用适配过对比度的强调色；主题状态同时驱动 CSS 变量与 Naive UI 配色。

- `CanvasAtmosphere` 使用圆弧、贝塞尔曲线与径向渐变形成应用内光场，不加载图片或持续运行的动画。曲线沿画布边缘延伸；其他页面降低光场强度，让表单和内容保持清晰。
- 目录与输入面板使用半透明表面和 `backdrop-filter` 磨砂；首页工作区信息通过 `MessageComposer` 的 `context` 插槽呈现，输入区只有一层容器边界。
- 外观设置可在「磨砂玻璃」与「纯色表面」之间切换，偏好保存在本机。系统要求减少透明度、或浏览器不支持模糊时使用实色表面。

- 苹方优先的系统字体栈，不分发字体文件；标题通过字重和字阶建立层级。
- Phosphor 图标统一通过 `AppIcon` 渲染，默认 Light，主导航选中时使用 Fill。
- 图标映射集中在 `app/utils/icons.ts`，按名称导入；不全局注册整个图标库。
- 页面标题、说明与操作由 `PageHeader` 统一；可复用卡片与抽屉独立成组件。
- 原色经 `accentPalette` 适配明暗表面的对比度；错误和成功使用独立语义色。
- Naive UI 负责表单、消息、对话框与抽屉等基础交互，自定义布局与视觉不受其默认组件外观约束。

## 响应式与动态效果

| 宽度 | 导航 | 内容 |
| --- | --- | --- |
| 大于 860px | 完整侧栏，可手动收起 | 卡片按可用空间排列，主要内容有最大宽度 |
| 601–860px | 图标侧栏 | 卡片自适应列数，工具栏可换行 |
| 600px 及以下 | 底部导航 | 单列内容，编辑抽屉不超过视口宽度 |

手机布局考虑底部安全区域，页面在剩余高度内滚动。键盘焦点使用清晰描边，图标按钮具有可读名称；选中状态不只依靠颜色表达。

单层窗口指前端画布没有额外框架，系统原生标题栏由桌面壳管理。本次磨砂在应用内容内部采样，不依赖桌面壁纸、macOS 原生 vibrancy 或平台私有 API；浏览器和桌面使用同一实现。

动态效果服务于反馈：页面短距离渐入、卡片悬停抬升、色板轻微缩放、列表增删过渡。遵循系统 `prefers-reduced-motion`，避免持续大幅运动。

## 实现边界

本次界面和提示词库位于 `src/frontend`，不改协议版本，不把进程管理或持久化后端逻辑引入页面。Agent 复制与编辑沿用 `agent.create/update`，状态和连接测试沿用原接口。

提示词库分为三个部分：

- `utils/prompts.ts`：内容校验、文件解析、变量识别与替换。
- `stores/promptStore.ts`：本地恢复、原子保存、增删与导入导出；只有写入成功后才更新内存状态。
- `PromptEditor`、`PromptUse` 与 `pages/prompts.vue`：编辑、变量预览与列表交互。

提示词库不与运行时数据库混用；位置和迁移方式在界面与[用户指南](customization.md)中明确。Agent Prompt 引用采用追加文字的方式，不建立隐藏的实时依赖。

## 可读性与验证

Vue、TypeScript 与 CSS 使用 Prettier 格式化。页面负责组合与流程，组件负责编辑与展示，解析和颜色计算放在纯函数中。新增代码不添加零散解释性注释。

在仓库根运行分层检查：

```bash
node scripts/tasks.mjs test-web
```

在 `src/frontend` 中使用 pnpm 11：

```bash
pnpm lint
pnpm format:check
pnpm test:e2e
pnpm generate
```

`pnpm format` 格式化应用代码；根任务 `fmt` 与 `lint` 已接入对应格式化命令。单元测试覆盖提示词恢复、导入失败不覆盖、变量替换、存储失败和强调色对比度；E2E 验证真实界面中的配置流程与响应式导航。
